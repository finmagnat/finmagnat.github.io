# finmagnat.github.io
Publisher website for Sokolov — Unity tools and game development.

Static HTML/CSS with no build step, JavaScript, or external dependencies.
Edit `index.html` to update content or add product articles; edit `styles.css` for styling.

GitHub Pages deploys from `master` → `/(root)` at https://finmagnat.github.io/.
The root `index.html` is the entry point; `.nojekyll` disables Jekyll processing.

To preview locally, serve this directory with any static HTTP server and open its local URL.
